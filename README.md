# Ouroboros Manifold — playtester site

Private playtest site. Unlisted `*.fly.dev` URL, no store link, no price. Please do not share the link.

Shows targets, not promises: nothing on this site is a screenshot of a finished game. Copy is pulled mechanically from `ouroboros-manifold`'s bible and MVP docs (`scripts/pull_content.py`) so the site cannot silently drift from what the bible actually says; concept art and the layer demo are explicitly labeled as design-phase work under evaluation.

## Structure

- `src/content/offers/*.md` — one file per offer from `distinctiveness.md`, regenerated by `scripts/pull_content.py`.
- `src/content/pages/*.md` — home and roadmap copy, same script.
- `src/pages/layers/` — interactive three.js demo of the layer-system idea, using real S-004/S-005 numbers from `E-01`.
- `public/models/` — three settled-reach unit GLBs used by the layer demo.
- `public/art/<page>/` — concept art Westley generates from the image prompt kit; empty until filled.

## Regenerating content

```sh
python3 scripts/pull_content.py --commit <sha>
```

Defaults to a pinned commit of `ouroboros-manifold` (see the script). Re-running overwrites `src/content/offers/*.md` and `src/content/pages/*.md` — hand-edited tone changes there are lost on regeneration, so check the diff before committing.

## Local dev

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
npm run preview  # serve the production build locally
```

## Deploy

```sh
fly deploy
```

`fly.toml` and `Dockerfile` build the Astro static output and serve it with Caddy. `min_machines_running = 0` — the app scales to zero between visits.
